# Mohamed Beshir — Portfolio

Personal portfolio of **Mohamed Beshir**, Full Stack Software Engineer (Laravel · Django · FastAPI · React · Next.js · Flutter · PostgreSQL).

- Live: <https://beshir.is-a.dev>
- Languages: Arabic (`/`) and English (`/en`)
- CV: [`/cv/Mohamed_Beshir_CV.pdf`](cv/Mohamed_Beshir_CV.pdf)
- LinkedIn: <https://linkedin.com/in/muhamed-b-antar>

## Structure

| Path | What |
| --- | --- |
| `index.html`, `en/index.html` | Static pages (Next.js export) |
| `_next/` | Bundled JS, CSS and fonts |
| `beshir-theme.css`, `beshir-theme.js` | Custom theme layer: colours, popup, CV section |
| `brand/`, `projects/`, `audio/`, `cv/` | Images, project covers, sounds, résumé |

## Run locally

```bash
node server.mjs   # http://localhost:4743
```

The site must be served from a root path (`/_next/...`), so open it through the server rather than double-clicking `index.html`.
